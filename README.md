# Desarrollo de Aplicaciones Móviles 1

Repositorio de la clase **Desarrollo de Aplicaciones Móviles 1**.

Cada carpeta dentro de este repositorio representa una tarea o proyecto de la clase.

## Estructura

| Carpeta | Descripción |
|--------|-------------|
| `Perfil-Usuario-Información-Detallada` | Tarea: Perfil de usuario con React Native, usando props entre componentes. |

## Cómo agregar nuevas tareas

1. Crea una nueva carpeta con el nombre de la tarea dentro de `Movil-1/`.
2. Desarrolla el proyecto dentro de esa carpeta.
3. Ejecuta los siguientes comandos para subir los cambios:

```bash
git add .
git commit -m "feat: agregar tarea [nombre de la tarea]"
git push origin main
```
